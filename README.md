# Планер

Веб-приложение для планирования: дела на день с сеткой часов, список задач, быстрый ввод строкой
(«Спортзал завтра в 18 1ч #здоровье»). Данные хранятся в браузере.

- `design/` — макеты экранов
- `web/` — приложение (Vite + React + TypeScript)

## Запуск локально

```bash
cd web
npm install
npm run dev
```

При пуше в `main` сайт собирается и публикуется на GitHub Pages.
